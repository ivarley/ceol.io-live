# Irish glossary (spec 057)

The words Ceol uses for its own ideas, in Irish, so each is translated the same way
everywhere. The product owner owns this list. Claude proposed the alternatives; the
product owner chose among them on 2026-10-06 (the "Ceol Irish Glossary" artifact). Every
term below is **agreed**. When a term changes, every string that uses it changes with it.

Names of tunes, sessions, places and people are data, not interface, and are never
translated. A new term is proposed here, marked "proposed", until the product owner
agrees it.
