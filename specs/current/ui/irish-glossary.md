# Irish glossary (spec 057)

The words Ceol uses for its own ideas, in Irish, so each is translated the same way
everywhere. The product owner owns this list. Claude proposed the first draft
(2026-10-06), in An Caighdeán Oifigiúil; nothing here is settled until it is marked
**agreed**. When a term changes, every string that uses it changes with it.

Names of tunes, sessions, places and people are data, not interface, and are never
translated.
